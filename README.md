# ai-image-classification

试图识别AI生成图片，将其区分与真实图片

\# 基于手写 ResNet18 的真假图像二分类项目介绍



\## 一、项目简介



本项目使用 Python 和 PyTorch，针对标记为 REAL（真实图像）与 FAKE（伪造图像）的数据，手动搭建 ResNet18 网络进行图像二分类。



项目希望通过带标签的图像训练模型，使其学习两类图像的特征，为后续真假图像识别提供分类模型。主要工作包括图像预处理、残差网络搭建、模型训练与验证、最佳权重保存，以及训练过程可视化。

此外，通过混淆矩阵和分类指标分析模型的正确分类、漏检与误报情况，并进行可视化

\## 二、项目实现的功能



\*\*1. 图像加载与预处理\*\*



数据集来源：\[CIFAKE：真实与人工智能生成的合成图像](https://www.kaggle.com/datasets/birdy654/cifake-real-and-ai-generated-synthetic-images?resource=download)

使用 torchvision 中的 ImageFolder，根据文件夹名称读取图像和类别标签。将图像统一调整为 224×224，并转换为张量，再通过 DataLoader 分批加载，为模型训练提供数据。



\*\*2. 手动搭建 ResNet18 网络\*\*



搭建残差块：

使用 PyTorch 的卷积层、批量归一化和 ReLU 激活函数搭建残差模块，通过跳跃连接将输入与卷积分支的输出相加。当特征图尺寸或通道数发生变化时，使用 1×1 卷积调整输入分支，使两条分支能够相加。



ResNet18网络实现：

在此基础上组合四组残差模块，并连接自适应平均池化层和全连接层，最终输出两个类别的分数。



\*\*3. 模型训练与验证\*\*



将训练目录中的数据随机划分为训练集和验证集，使用交叉熵损失函数衡量分类误差，通过 Adam 优化器更新模型参数。每轮训练统计训练集和验证集的损失、准确率，以观察模型学习情况。



\*\*4. 自动选择运行设备\*\*



根据 CUDA 是否可用，选择在 GPU 或 CPU 上运行模型。



\*\*5. 保存最佳模型权重\*\*



训练过程中根据验证集准确率记录表现最好的模型，训练结束后保存对应权重，方便后续加载和预测。



\*\*6. 展示训练曲线\*\*



使用 Pandas 整理每轮训练记录，通过 Matplotlib 绘制训练与验证的损失曲线、准确率曲线，帮助分析训练过程。



\*\*7. 模型测试与分类表现分析\*\*



加载已有模型权重，在独立测试集上进行预测，比较预测标签与真实标签，计算总体测试准确率。



使用 NumPy 构建混淆矩阵，分别统计 REAL 和 FAKE 的正确分类与错误分类数量，并计算两个类别的精确率（Precision）、召回率（Recall）和 F1 分数，分析模型是否存在较多误报或漏检。



\## 三、使用的技术



项目以 Python 为开发语言，主要使用以下工具：



\- \*\*PyTorch\*\*：实现网络结构、损失计算、自动求导和参数更新。

&#x20;   

\- \*\*torchvision\*\*：完成图像数据加载和预处理。

&#x20;   

\- \*\*Pandas\*\*：整理每轮训练与验证的指标。

&#x20;   

\- \*\*Matplotlib\*\*：绘制损失曲线和准确率曲线。

&#x20;

当前训练脚本设置的批次大小为 32，训练轮数为 20，Adam 学习率为 0.001。



\## 四、本次测试结果与分析



使用当前已有模型权重，对测试目录中的 20,000 张图片进行评价，其中 FAKE 和 REAL 各 10,000 张。



本次测试中，模型正确分类 19,185 张，错误分类 815 张，总体准确率为 \*\*95.925%\*\*。



具体分类情况如下：



\- \*\*实际为 FAKE 的图片\*\*：9,578 张被正确识别，422 张被误判为 REAL。

&#x20;   

\- \*\*实际为 REAL 的图片\*\*：9,607 张被正确识别，393 张被误判为 FAKE。

&#x20;   



根据混淆矩阵计算：



\- \*\*FAKE 类\*\*：精确率约为 \*\*96.06%\*\*，召回率为 \*\*95.78%\*\*，F1 约为 \*\*95.92%\*\*。

&#x20;   

\- \*\*REAL 类\*\*：精确率约为 \*\*95.79%\*\*，召回率为 \*\*96.07%\*\*，F1 约为 \*\*95.93%\*\*。

&#x20;   



两类的 F1 接近，说明在本次测试中，模型对两类图片的综合分类表现相近。其中，生成图像的漏检率为 4.22%，真实图像被误报为生成图像的比例为 3.93%。

\## 六、问题的解决与处理



\### 神经网络训练过程中图片尺寸对训练结果有什么影响



\#### ResNet18 因为在全连接前有 自适应平均池化，经过自适应池化，都会成为 \*\*512×1×1\*\*，展平后固定是 \*\*512 个数\*\*，所以全连接层能够接收。所以ResNet可以适应各种图像尺寸

\#### 像素越高，相对需要的网络更复杂，优化技术更好，训练时间更长，超参数设置，对错待定
